# RockStock

**Descripción del sistema:**
RockStock es un sistema de información a la medida que permite a una empresa de superficies de piedra natural y tecnológica controlar su inventario de materiales: registrar qué entra al almacén, qué sale por transformación o venta, y llevar el control de existencias en tiempo real, incluyendo alertas de stock mínimo.
